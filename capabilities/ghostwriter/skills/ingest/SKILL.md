# Ingest Content Ideas

1. Run {{skill: ghostwriter}}'s successful backlog preflight before any state change. If unavailable or failing, stop. If the queue is full, dismiss or develop before adding.
2. Retrieve relevant InterviewRecords and KB sources from `{{mod: kb_base}}`. Keep factual retrieval separate from voice examples.
3. Build a bounded evidence packet. Every proposed claim points to a source or is marked `needs-confirmation`; record claim/atom, source path, turn or line range, sensitivity, and confirmation state in the idea's `## Evidence map`.
4. Produce 2–4 ideas, each with title, short synopsis, source references, evidence strength, and visible sensitivity flags.
5. Save only proposals the user keeps, using `templates/idea.md`; rejected new proposals leave no artifact. If the user later dismisses an already-queued idea, set it to `dismissed` and archive it under `archive/ideas/`.

An abstract is an idea, not a draft. Do not create prose or a piece folder until selected.
