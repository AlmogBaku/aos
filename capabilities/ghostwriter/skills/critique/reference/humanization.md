# Final edit

Facts are sacred. Do not add length.

Check for:
- generic AI vocabulary and transitions;
- uniform sentence rhythm;
- symmetrical intro/conclusion;
- repeated threes and unnecessary summaries;
- archetypes where a sourced instance exists;
- false balance that hides the author's actual position;
- explanations the target reader already knows.

Fix only what is present. Run once. Further improvement comes from the author's edits, not repeated model rewrites.
